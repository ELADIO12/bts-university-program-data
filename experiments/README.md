# Experimental content boundary

There are no synthetic course records in this delivery. `data/programs/` holds only the Oxford research records with field evidence; `site/` is generated from those validated records.

Future synthetic importer variants belong here, clearly marked experimental, and must use a separate output directory/deployment. The current pipeline reads only `data/programs/*.json` and cannot publish fixtures from this directory. Do not weaken evidence checks to insert a fake value. Keep sanitized compatibility results here only after reviewing them for secrets and personal data. No importer has been contacted.
